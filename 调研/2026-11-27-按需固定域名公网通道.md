# 按需开启的免费固定域名通道（2026-11-27）

需求：电脑需要时启动，关闭后释放资源；下次启动手机配置的域名不变。当前脚本仍使用 Cloudflare Quick Tunnel，仅作为过渡。

| 方案 | 固定地址与费用 | 与 HiFairy 的关系 |
| --- | --- | --- |
| ngrok Free | 账号分配一个固定 `*.ngrok-free.dev` 域名，关闭再启动仍相同；免费额度为每月 1 GB 出站流量、2 万 HTTP 请求、5000 TCP 连接 | 无需购买域名，最适合先做固定地址试验；免费版有浏览器警告页，必须真机验证 WebSocket 语音与 Agent 是否直达、额度是否够用 |
| Tailscale Funnel | 官方说明可提供稳定 HTTPS URL，无需自有域名；Personal 计划免费 | 备选。需在电脑安装并登录 Tailscale，开启 MagicDNS 与 HTTPS；Funnel 有不可配置的带宽限制，先测手机异网 WebSocket、长连接及实际可用性 |
| Cloudflare Named Tunnel | Tunnel 可免费使用，绑定自有域名下的固定主机名；域名本身可能需要购买或续费 | 若已有域名，适合作为后续方案；无需保持通道全天在线。Quick Tunnel 不具固定域名能力 |
| 免费 SSH 反向隧道（localhost.run / Pinggy） | 只需系统 `ssh` 客户端，能按需开放本机端口；免费地址通常会变 | 适合临时调试，不满足“下次域名不变”的主要目标。Pinggy 免费通道 60 分钟超时；localhost.run 免费域名官方称会定期变化，虽称 SSH key 有助于保留名称，也没有同等的固定域名承诺 |
| 自有 VPS + SSH `-R` | VPS 固定 IP/域名可实现固定入口；若已有 VPS，软件本身无额外费用 | 需要维护服务器、TLS 反向代理、鉴权和 SSH 自动重连；Oracle Always Free 是一种免费 VM 来源，但注册、容量和空闲回收均有条件，运维量高于上述托管通道 |

推荐顺序：先用 ngrok Free 固定开发域名做手机真实语音流、Agent WebSocket 与文件上传下载测试；若免费额度或警告页影响实际调用，再试 Tailscale Funnel；已有自有域名时可改 Cloudflare Named Tunnel。域名不变不代表服务在电脑关闭时可用，启动后仍需等待本地模型/网关及通道就绪。长期服务可靠性与自动恢复是独立事项。
