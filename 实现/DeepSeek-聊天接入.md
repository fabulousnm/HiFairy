# DeepSeek 聊天接入

2026-11-18 已实现首版：设置页输入 DeepSeek API Key、模型 ID 和思考强度；发送文本后调用官方 Chat Completions 流式接口，将 `delta.content` 逐段显示。API Key 使用 Android Keystore AES-GCM 加密后保存在私有 SharedPreferences；模型和强度是普通设置。缺少 Key 时跳转设置页。

当前默认模型为 `deepseek-flash`，思考强度为 `high`，可手动修改为官方支持的 ID 和 `none/low/high/max`。尚未接入模型列表能力查询、分页与长会话裁剪。构建通过，真实 API 请求待用户在应用内填写 Key 后验证。

同日修复：流式 `delta.content` 为 JSON null 时不追加文字；消息使用 Markwon 4.6.2 渲染 Markdown 与 LaTeX，兼容 `\\[...\\]`、`\\(...\\)` 分隔符；会话区可纵向滚动。输入框显式使用浅色文字和光标。设置页使用独立返回导航、分组卡片与暗色输入组件。APK 构建通过；真机上的公式显示和长对话手势仍需在用户设备上验收。

后续真机截图暴露行内 `$$...$$` 未渲染：Markwon 的行内公式开关默认关闭，现显式启用。聊天界面改为左右会话气泡，Fairy 使用眼徽头像，用户头像支持“铃”“哲”和自选图片，昵称默认“绳匠”。头像与昵称保存在本机设置中。滚动区的上边界置于固定眼徽下方，代码块背景色比 Fairy 气泡深。主题色取自已授权参考仓库的暗色令牌：其气泡色为 `rgba(22,26,42,0.92)`，代码块色为 `rgba(8,9,20,0.94)`；用户气泡使用同系蓝紫色以区分说话者。新增表格、删除线和任务列表渲染插件。真机公式和长消息排版仍需验收。

头像修正：聊天和设置统一使用正方形容器、圆形裁切及居中裁剪；默认“铃”“哲”素材略微放大以去掉图片内置白边。聊天双方容器尺寸均为 36dp。

本阶段增加思考内容分离展示：流式 `delta.reasoning_content` 保存在消息的 `reasoning` 字段，显示为与回答气泡颜色不同的可展开区域；`delta.content` 仍作为正式回答。思考强度设置为 `none` 时不会出现思考区域。新增本机会话持久化、历史列表、重命名、删除、停止生成、重新生成、复制回答，以及编辑用户消息并重新生成后续回答。存储文件为应用私有目录的 `conversations.json`。历史仅保存在本机，不包含跨设备同步。联网搜索、文件上传、语音转写与播报尚未接入。

消息操作使用应用绘制的图标，避免设备字体缺字导致图标不可见；各按钮有无障碍描述和 40dp 点击区域。每条 Fairy 回答下方都有复制按钮，重新生成只出现在最新一条 Fairy 回答旁；编辑按钮仅出现在最近一条用户消息下方。进入编辑时输入框改用蓝色边框与编辑图标，浅色取消按钮位于发送按钮左侧。

历史会话使用左侧 3/4 屏宽抽屉；打开时对话界面向右移动、略微缩小并透视后退，右侧保留约 1/4 可点击区域以收起抽屉，系统返回也可收起。抽屉带圆角与阴影，叠放在对话界面上层。每条会话右侧用三点菜单收纳重命名、删除；点击会话标题切换会话，新对话和设置入口保留在抽屉中。

右侧露出的对话界面覆盖半透明浅蓝遮罩；左侧当前会话卡片使用比其他会话更深的颜色。

抽屉支持水平拖动展开和收回，松手按拖动进度或速度吸附到开/关状态。对话页位移、缩放、透视和遮罩强度共用同一进度值；遮罩只位于右侧露出的对话区域，横向从透明渐变到浅蓝，并随抽屉展开逐步增强。

松手规则使用方向相关阈值：从关闭状态拉出约 38% 后自动展开，未达到则弹回；从打开状态拉回约 38% 后自动收起，未达到则弹回。快速甩动按速度决定方向。吸附使用带阻尼的弹簧动画，对话页在终点有轻微回弹。

修复慢速拖动后停在中间的问题：拖动期间同步更新手势进度，松手时只启动一次到 0 或 1 的弹簧吸附，并在结束时精确归位。抽屉现在只有完全收起和完全展开两个稳定状态。

历史会话按钮统一采用拟物样式：普通会话使用纯色底面、外侧阴影和亮边；当前会话使用更深的纯色底面、纯色边框与内嵌阴影。按钮本身不使用渐变，标题颜色区分当前会话。三点菜单与抽屉手势保持原有行为。

冷启动完成开屏动画后显示空白新对话，历史会话保留在抽屉中。问候语按手机当前小时选择“早上好，主人”（05:00–11:59）、“下午好，主人”（12:00–17:59）或“晚上好，主人”（其余时段），居中置于眼徽下方；应用重新回到前台时刷新时段。系统返回按设置来源返回抽屉或聊天，从抽屉返回聊天，编辑中先取消编辑；从历史进入聊天时返回抽屉。根聊天页按返回键将应用任务移到后台，保留当前进程中的会话状态。
