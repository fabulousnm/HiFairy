# 离线中文语音输入

2026-11-18：聊天输入栏接入 Vosk 流式中文识别。点击麦克风首次加载打包在 APK 内的 `vosk-model-small-cn-0.22`，随后开始录音；局部识别结果实时填入输入框，点击停止后追加最终结果，用户确认文字后再发送。麦克风权限按需请求，模型加载、识别和停止状态显示在输入栏下方。此前设置页的录放音设备测试已完成使命并移除。

选用官方移动端中文小模型，而非项目简述提到的 `vosk-model-cn-0.22`：前者压缩包约 42MB、解压后约 68MB；后者压缩包约 1.3GB，官方定位为服务器模型。这个选择优先保证手机上的启动与识别速度，识别准确度需要在 nova 14 上实测。模型来源为 [Vosk 官方模型页](https://alphacephei.com/vosk/models)，许可证 Apache 2.0；Android 集成参考 [官方示例](https://github.com/alphacep/vosk-android-demo)。下载 ZIP 的 SHA-256 为 `3AF8B0E7E0F835AE9D414CE5DF580237A3CFB08D586C9FBBB0F7FF29AD5B14BA`。

验证：`assembleDebug` 构建成功，APK 约 105.7MB。当前 ADB 没有设备，无法验证真机识别、实时延迟与准确率。下阶段应实测，并接入语音播报。
