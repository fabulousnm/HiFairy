# 语音识别基准

测试包：`voice-lab/build/outputs/apk/debug/voice-lab-debug.apk`，安装标识 `com.hifairy.voicelab`，与正式应用互不覆盖。内含 Zipformer CTC INT8、Paraformer small INT8、SenseVoiceSmall INT8 三种模型，均通过 sherpa-onnx 在本机运行；Vosk 小模型已从新版测试包移除。

构建新测试包前执行 `powershell -ExecutionPolicy Bypass -File voice-lab/prepare-models.ps1`。脚本下载固定版本的 sherpa-onnx AAR 和三个模型、校验 SHA-256，再复制所需文件到被 Git 忽略的本地素材目录。之后执行 `./gradlew :voice-lab:assembleDebug`。模型二进制不进入 Git；APK 内含全部模型。仅构建 arm64 版本，目标为 nova 14。

## 真机步骤

1. 在 nova 14 的卓易通中安装测试 APK，打开后授予麦克风权限。
2. 朗读屏幕参考句，只录制一次；点击“停止录音”。
3. 依次选择 Zipformer、Paraformer、SenseVoice，分别点击“用所选模型识别本次录音”。三次识别使用**完全相同的音频**。
4. 点击“复制三模型报告”，保存或发回报告；特别标记误识别的专有名词、数字和长句。按“下一条测试句”继续下一组。

字符错误率 CER = 编辑距离 / 参考文本字符数。计算时忽略标点和空格；越低越好。本版使用**录音后的同音频解码**，分别记录模型加载时间和推理时间，不能据此推断实时首字延迟。每次识别重新加载所选模型，避免手机同时保留三个大模型。

## 当前结论

三模型测试包构建通过，APK 约 286MB，仅打包 arm64 运行库。尚无可连接的 ADB 设备和用户语音样本，不能宣称准确率达标。真机报告将决定后续选型与是否重新整合。
