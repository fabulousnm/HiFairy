# 语音识别基准

测试包：`voice-lab/build/outputs/apk/debug/voice-lab-debug.apk`，安装标识 `com.hifairy.voicelab`，与正式应用互不覆盖。模型为 Vosk `vosk-model-small-cn-0.22`。

## 真机步骤

1. 在 nova 14 的卓易通中安装测试 APK，打开后授予麦克风权限。
2. 在安静环境中，按屏幕参考句朗读，点击“停止并计算准确率”。每句重复三次。
3. 点击“复制测试报告”，保存或发回报告；特别标记误识别的专有名词、数字和长句。
4. 在日常噪声环境中再测一轮，记录与安静环境的差异。

字符错误率 CER = 编辑距离 / 参考文本字符数。计算时忽略标点和空格；越低越好。首字延迟从开始录音到首个非空局部识别结果。首次模型加载时间单独记录。

## 当前结论

正式应用与测试包均构建通过；尚无可连接的 ADB 设备和用户语音样本，不能宣称准确率达标。官方[模型表](https://alphacephei.com/vosk/models)显示，中文小模型在 SpeechIO-02 上的错误率为 23.54%，大模型为 13.98%；这是公开数据集指标，不能替代本机测试。后续需要按真机报告判断是否改用更适合移动端的识别方案。
