测试包：`workspace-lab/build/outputs/apk/debug/workspace-lab-debug.apk`，应用标识 `com.hifairy.workspacelab`，与 HiFairy 正式包隔离。

## 真机操作

1. 在鸿蒙文件管理中先新建一个专用测试文件夹。若要验证鸿蒙本机文件，选择器里尝试进入 `MyHarmonyDevice` 后选该文件夹；不要选有重要数据的目录。
2. 安装并打开“HiFairy 文件权限测试”，点击“手动挂载测试文件夹”。
3. 点击“创建、覆盖写入并读回校验”。测试包只会创建 `HiFairy-test-xxxxxxxx.txt`，先写一版，再覆盖该文件并读回比较；不修改文件夹内的其他文件。
4. 若目录测试提示 `Failed to touch / Permission denied`，点击“系统选择器新建单个测试文件”，在相同的 `Test` 文件夹中保存，等待单文件写入、读回与覆盖结果。这个测试由系统逐个文件授权，用于区分目录创建与单文件写入能力。请截图结果。
5. 如有成功写入的文件，用鸿蒙原生文件管理确认内容。关闭并重新打开测试包，先点“检查重启后授权”，再点目录测试按钮，验证目录授权能否持续。
6. 将测试页面结果截图反馈，并注明目录来源。解除挂载只会撤销目录授权，测试文件会保留。

## 判定

- **完整通过**：目录选择、持久读写授权、创建、覆盖、读回，以及鸿蒙文件管理可见均成功；重启后可再次写入。
- **仅兼容区通过**：卓易通环境目录成功，`MyHarmonyDevice` 无法选择或写入。则 APK 可操作兼容区工作区，但不能据此声称能操作原生鸿蒙文件。
- **目录授权不支持**：选择器没有写入授权或 `takePersistableUriPermission` 失败；需改为逐个文件授权或规划鸿蒙原生模块。

## DSH 到手机端到端测试

正式 HiFairy 包新增“设置 → 手机工作区 → 挂载与测试”。在同一个兼容区普通测试目录重新挂载，因为独立测试包的授权不会共享给正式包。先运行本机探针，确认正式包内也能写入。然后保持手机 Agent 会话在前台且连接电脑，在该会话发送“请调用 hifairy_phone_workspace_probe 测试我挂载的手机工作区”。DSH 工具经当前会话的事件流将固定 `probe` 请求传给手机；手机使用其本机 SAF 授权执行，结果通过同一 Agent 网关回传。该远程协议无空闲轮询，只有活动会话的 WebSocket。

远程固定探针只创建/覆盖 `HiFairy-agent-test-*.txt`，不支持任意读写、删除或访问绝对路径；必须保持该手机会话在前台。目录总数不再受 20 条限制，全部名称通过后续分页工具读取。

源码改动不会使已加载插件或 Python 模块自动更新。自动重启 DSH 的命令曾被本机执行策略拒绝。需要手动重启 DSH 以加载 Host 与工具插件；网关若仍为旧进程，还需重启一键服务器，临时 Cloudflare 地址可能变化。确认新 Host 路由 `POST /sessions/<id>/phone-workspace-result` 对无效请求返回 400（旧版返回 405）后进行真机测试。

## 503 排查记录

用户反馈 Agent 返回 503。检查发现本地网关 `/health` 为 200，但 `/agent/sessions` 返回 `bridge_unavailable`，`127.0.0.1:18765` 没有监听；因此 503 出自网关到 DSH 桥接，和手机挂载目录授权无关。上一版将 `tools` 注入原 Host 桥接插件，疑似使 Host 插件因服务依赖未满足而无法启动。已拆为独立 `phone-workspace-tool` 插件，原 Host 恢复原有依赖；两者通过仅监听回环地址的鉴权 HTTP 接口协作。代码测试通过，需 DSH 手动重启后确认 18765 恢复。手机端对 `bridge_unavailable` 改为明确提示检查电脑桥接。

后续验证：DSH 重启后 Host `/sessions` 和网关 `/agent/sessions` 均返回 200，503 已消失；但 DSH 当前会话看不到 `hifairy_phone_workspace_probe`。宿主崩溃日志指出工具插件 schema 的 `properties.text.required` 不受支持，导致该插件未激活。现已将必填字段声明改为对象层 `required: ['text']`；需再次重启 DSH，确认工具出现在新 Agent 会话里。

第二次重启后检测到新 DSH 宿主进程、Host `/sessions` 返回 200，且没有新工具插件加载错误日志。仍需在手机当前或新建 Agent 会话实际调用 `hifairy_phone_workspace_probe`，确认工具暴露与手机端执行结果。

## 正式文件插件：一次对话验收六项

现有 DSH `hifairy-phone-workspace-tool` 插件新增自然语言可发现的六个正式工具：列目录、读 UTF-8 文本、新建或覆盖文本、新建目录、重命名、删除单个文件。用户在 DSH 对话里说“输出到手机端的挂载文件夹中”即可触发写入工具，无需记忆或点名工具名。所有请求仍通过当前手机 Agent 会话事件流下发，由手机本地 SAF 对手动挂载的目录执行；手机不在该会话前台时不会执行。

安全边界：只接受挂载根目录内的相对路径，每一级经 SAF 子目录查找；拒绝绝对路径、`..`、反斜杠和盘符。文本读上限 12 KB，写上限 8 KB；已存在文件必须显式 `overwrite=true` 才覆盖，并在覆盖前确认是可读取的小文本。重命名仅在同一目录内且不覆盖已有名称。删除仅支持单个文件，不支持目录或递归删除。文本写入后读回校验。若某文件超过上限，工具明确报错而不修改它。
